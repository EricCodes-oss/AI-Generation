# 双休议题视频制作计划

> 按用户连续执行指示在本会话直接执行；质量检查由当前执行者完成，不设普通确认门。

**Goal:** 制作默认主持人和默认音色的双休议题净版 MP4。

**Architecture:** 使用既有语音与数字人接口生成当前文案的新音频和口型；FFmpeg 做原构图动态剪辑和本地输出。旁路 JSON 记录事实、素材、任务和验证证据。

**Tech Stack:** Python、Giggle API、FFmpeg、ffprobe、Apple Vision。

## 全局约束

遵循对应设计文档的主持人哈希、音色、9:16 净版技术规格和所有动态/中国语境硬门。素材下载失败改用公开 API 与来源站点，不绕过付费或访问限制。无法核验的新闻断言不写入口播。

- [ ] 获取参考元数据和画面结构，查询权威法律与事件报道，保存证据。
- [ ] 编写原创开场、插播旁白和结尾，检查每项事实，提交默认音色并保存任务 ID。
- [ ] 下载高质量中国语境插播候选，联系表逐镜审核，记录人物、水印、标题和动作完整性。
- [ ] 取得语音后生成当前开场和结尾数字人，校核音频对齐、嘴部运动和主持人身份。
- [ ] 按自然语速匹配足够长的连续素材，所有插播速度1.0、比例不大于1.0，无冻结或循环。
- [ ] 渲染完整节目并做解码、规格、静音、黑帧、冻结、音频母版和导演视觉复核。
- [ ] 仅在所有硬门通过后交付净版 MP4，以及文稿、来源、时间线、QC 和 SHA-256 直接路径。
