# BV17新闻制作计划

**Goal:** 按指定原片和固定主持人制作经完整质检的新闻净版。

**Architecture:** 复用已有本地配音、数字人和FFmpeg剪辑工具；本期独立目录保存素材、文稿、任务记录与交付文件。

- [x] 获取原片高清画面和音轨，核对标题、发布者、时间及现场语境。
- [x] 原声转写、字幕交叉校正，拆为开场、插播旁白、结尾；保存完整文稿。
- [x] 默认音色正常语速配音；固定短发主持人生成开头结尾，复核口型。
- [x] 原片干净动态镜头逐句映射，裁切在扩展背景前完成，剔除主持人和新闻包装。
- [x] 合成1080×1920、25fps、AAC48kHz净版；输出完整节目台词和来源账本。
- [x] 全片解码、音轨匹配、OCR、人像与中国语境、主体动态、导演复核、SHA256校验后直接交付。
