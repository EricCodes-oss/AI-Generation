# 民生利益优先与重大灾害突发热点筛选设计

## 目标

把《秸秆禁烧不再“一刀切”》的成功经验固化进 V5 热点双漏斗：优先识别与普通人钱袋子、就医、就业、教育、住房、养老、农村生产和日常消费直接相关的规则变化；同时建立地震、洪水、台风、山火、滑坡、泥石流和极端天气等重大自然灾害的独立突发通道。候选确认仍是生产前唯一常规用户门。

## 方案选择

采用混合方案，而不是只增加一个分数或只建立一个独立榜单：

1. 建立“民生利益候选池”，从全网注意力信号中先筛选直接影响普通人的议题；
2. 建立“重大灾害突发通道”，满足严重性和权威核验门槛的事件可绕过普通热度排序进入优先评估；
3. 两类候选与通用热点统一进入最终导演评分，输出结构化候选卡；
4. 使用历史成片去重和账号成功案例反馈修正排序，但不得用历史表现替代当日事实与热度证据。

该方案既避免民生题被娱乐热搜淹没，也避免把轻微天气变化包装成重大灾害。

## 候选采集

原始信号覆盖百度、头条、B 站、抖音、小红书、微博、X/Twitter，以及新华社、新华网、人民日报、中国青年报、中央广播电视总台和政府部门等权威来源。平台热榜只证明注意力，不单独证明事实。

每轮采集至少覆盖：

- 钱袋子：社保、医保、公积金、税费、补贴、养老金、贷款与公共收费；
- 看病养老：报销、药价、异地结算、长期护理、基层医疗；
- 上班族权益：工时、休假、合同、社保、工伤、失业、灵活就业；
- 教育家庭：入学、考试、学费、助学、托育、校园收费与餐食；
- 农村基层：耕地、宅基地、农资、粮价、秸秆、农民工工资；
- 消费生活：住房、物业、租赁、预付卡、食品安全、通信与交通；
- 普通人真实生活与正能量瞬间；
- 重大自然灾害与次生风险。

## 民生评分

候选基础分为 100 分：

- 普通人直接影响：25；
- 时效性或实施临近度：20；
- 认知冲突、误解澄清价值：20；
- 受影响人群规模：15；
- 真实、有表现力的画面条件：10；
- 权威证据完整度：10。

候选卡必须回答：谁受影响、从哪天开始、钱或权利是否变化、旧规则与新规则有何不同、是否需要申请或行动、网络说法是否准确、全国统一还是地方细化、例外和边界是什么。

历史成功案例只形成可解释的“编辑反馈标签”，例如“明确实施日期”“政策变化”“反常识澄清”“农村切身利益”；不得虚构平台数据，也不得使缺乏当日热度或权威证据的话题入选。

## 重大灾害突发通道

### 进入条件

地震、洪水、台风、山火、滑坡、泥石流、极端高温或其他自然灾害，满足以下任一事实严重性指标，并有权威来源核验，进入突发优先池：

- 已报告人员伤亡、失联或大规模紧急救援；
- 已发生较大规模人员转移安置；
- 重要道路、铁路、机场、电力、通信或供水明显中断；
- 国家或省级部门启动应急响应；
- 灾害仍在发展，且存在明确的次生灾害或公众避险需求。

地震震级、降雨量或风力只作为事件参数，不单独替代影响评估。没有现实影响、仅有普通预警或旧灾情翻炒的内容不得走突发通道。

### 核验与伦理边界

- 至少一项政府、应急、气象、地震、消防或主流央媒的一手事实证据；
- 伤亡数字、响应级别、发生时间和地点必须标注更新时间；
- 灾情发展中存在冲突数字时，以“截至具体时间”的方式表述并保留差异；
- 素材必须核对时间、地点和事件，严禁错配旧画面；
- 不使用血腥、近距离伤亡和可能暴露受害者隐私的画面；
- 标题强调事实、救援、影响或避险，不消费灾难，不夸大恐慌。

## 去重与排序

扫描工作区和输出目录中的历史 `topic-selection.json`。同一事件或同一作品即使标题角度略有变化，也执行冷却；有实质新进展时允许重新进入，但候选卡必须说明新增事实。

最终排序规则：

1. 通过重大灾害突发门且仍在发展的事件；
2. 民生利益分高、当日多源热度明确、事实完整的候选；
3. 普通人真实自然瞬间；
4. 其他跨领域 S/A 级热点。

不为凑数量补弱题。候选最多 8 个，可以少于 3 个，也可以明确报告没有合格候选。

## 候选卡输出

每张卡输出：

- 新闻事件与建议标题；
- 影响人群和切身利益；
- 最新进展与具体日期；
- 热度依据和跨平台覆盖；
- 传播冲突及必须澄清的误解；
- 普通人是否需要行动；
- 权威事实来源；
- 可用真实画面、现场原声价值和素材风险；
- 历史去重结果；
- 民生六项评分、突发通道状态和导演评级。

## 工作流

导入候选时自动完成模型校验、历史去重、民生评分排序和突发通道检查，生成 JSON 与 Markdown 候选卡。用户选择候选后，按 AGENTS.md 连续执行事实核验、稿件、TTS、数字人、素材、剪辑、字幕文本、自动 QC、导演 QC 和交付，不再逐步询问。
