# 三平台真实热点采集与无水印素材设计

日期：2026-08-07  
状态：待用户书面复核  
适用项目：固定演播室主持人 + 竖屏新闻画面插播

## 1. 目标

为每日一条短视频建立可追溯、只读、不可伪造的真实热点采集环节，覆盖：

- 抖音；
- 微信视频号；
- 小红书；
- 官方机构、主流媒体或事件当事方公开信息，用于事实核验。

手动模式只在采集完成后提供 Top 3 热点确认卡，不增加新的人工确认点。托管模式使用相同采集和安全规则，但自动选择最高分合格热点。

## 2. 已确认的产品规则

1. 允许 Agent 复用用户本机 Chrome 已登录状态，只读取公开页面。
2. 禁止点赞、评论、收藏、关注、私信、发布或修改账号资料。
3. 默认检索最近 72 小时；不足 3 个合格热点时扩展到最近 7 天。
4. 候选热点必须满足以下任一条件：
   - 至少在两个目标平台出现；
   - 一个目标平台达到相对高热度，并有官方或权威来源证实。
5. 有热度但未证实、来源冲突、恶意传言或高风险内容不进入正式候选池。
6. 任何不可见的互动数据保持 `unknown/null`，禁止估算、补齐或虚构。
7. 热点平台视频只用于研究、热度证明和脚本参考，默认不作为成片素材。
8. 带平台水印、账号标识、二维码或授权不清的素材不得进入成片；不通过裁剪、遮挡、模糊或 AI 擦除水印规避。

## 3. 推荐架构：混合只读采集

采用“Agent 浏览器采集 + 可选 OpenCLI 适配器 + 项目统一标准化”的混合结构。

### 3.1 采集层

- **抖音**：优先通过已登录 Chrome 搜索页、热点页或公开视频页读取可见字段；OpenCLI 能力探测成功后可作为加速适配器。
- **小红书**：优先通过已登录 Chrome 搜索结果和笔记详情读取可见字段；OpenCLI 能力探测成功后可作为加速适配器。
- **视频号**：使用微信登录态可访问的浏览器界面进行辅助采集；若页面不能稳定自动读取，则导出为项目规定的结构化只读记录，并标注 `browser_assisted`，不能用公众号文章冒充视频号来源。
- **公众号文章**：`wechat-article-search` 只作为事实背景或权威补充来源，不计为视频号平台热度。

第三方 Skill 的“已安装”不等于真实平台已可用。每次采集前必须执行能力探测，并记录平台、登录态、命令、页面访问和可见字段的实际结果。

### 3.2 Agent 与项目代码边界

Chrome 登录态由 Agent 在浏览器环境中使用，不把 Cookie、Token 或密码写入仓库、日志、原始数据或命令行参数。

项目代码负责：

- 接收 Agent/OpenCLI 输出的结构化采集包；
- 校验来源与字段；
- 保存不含认证信息的原始证据摘要；
- 标准化互动数据；
- 去重、聚类、事实核验、评分和 Top 3 报告；
- 将选定热点交给现有脚本流程。

这样可以复用浏览器登录状态，又不会让普通 CLI 直接持有用户凭证。

## 4. 统一采集记录

每条平台记录至少包含：

```text
platform
content_id
canonical_url
account_name
account_id（页面可见时）
title_or_caption
published_at
collected_at
query
visible_metrics:
  views
  likes
  comments
  favorites
  shares
metric_visibility
collector_method
raw_evidence_reference
```

约束：

- `canonical_url` 与 `content_id` 至少有一个；
- `published_at` 不可确定时必须明确标注；
- 每个互动字段独立记录可见性；
- 平台将“点赞”显示为模糊值时保留原始文本，并在可安全解析时另存数值；
- 不复制完整视频、完整台词、长文章正文或大段评论；
- 原始证据仅保存必要的页面摘要、采集时间、来源链接和可见数值。

## 5. 去重与热点聚类

分两级去重：

1. **同平台去重**：按规范化 URL、内容 ID、账号和标题相似度合并重复记录。
2. **跨平台聚类**：按事件主体、时间、地点、核心事实和语义相似度将不同平台内容归为同一热点。

不能只因使用相似情绪词就合并。例如“年轻人裸辞”和“中年人转行”可以属于同一内容方向，但不是同一个热点事件。

每个热点簇保留：

- 各平台来源列表；
- 首次和最近出现时间；
- 各平台可见互动数据；
- 事实核验来源；
- 数据缺口与冲突；
- 被排除来源及原因。

## 6. 热度分析与 Top 3

不直接比较不同平台的绝对点赞量。先在同平台、同时间窗口、同类内容中计算相对热度，再合并评分。

建议总分组成：

- 平台内相对热度：35%；
- 跨平台共振：25%；
- 时效性：15%；
- 评论讨论质量：10%；
- 与栏目受众和内容支柱匹配度：10%；
- 来源完整度：5%。

事实可信度不是加分项，而是前置门槛。风险内容、未证实内容、恶意攻击、隐私泄露和明显营销操纵直接排除。

采集先覆盖较大的候选池，形成热点簇后再筛选。对最终候选可抽取每个热点 10–20 条公开代表性评论，用于判断：

- 用户情绪；
- 主要争议；
- 真实处境；
- 适合主持人讲解的切入角度。

评论仅作聚合洞察，避免保存不必要的用户身份信息。

若最近 72 小时不足 3 个合格热点，则扩展至最近 7 天；扩展后仍不足 3 个时，只展示真实合格数量并说明缺口，不用低质量或虚构候选补位。

## 7. 事实核验与风险排除

候选进入 Top 3 前必须建立事实核验卡：

- 核心事实；
- 权威来源链接或引用标识；
- 来源发布日期；
- 平台热度内容与权威事实之间的对应关系；
- 已确认事实、合理解读、未知信息三层分离；
- 是否涉及未成年人、灾害、医疗、金融、司法案件、个人隐私等敏感领域。

出现以下任一情况时自动跳过并寻找下一个候选：

- 只有搬运号或匿名账号传播；
- 权威来源否认或来源之间存在关键冲突；
- 标题与原始事实明显不符；
- 主要依赖侮辱、造谣、猎奇伤害或隐私泄露获得热度；
- 无法在制作周期内完成可靠核验。

## 8. 热点证据与成片素材隔离

建立两个完全分离的对象：

### 8.1 热点证据

用于证明“这个话题正在被讨论”，可以记录平台链接、页面摘要、互动量和代表性评论。热点证据不得自动成为剪辑素材。

### 8.2 成片素材

插播画面按以下顺序选择：

1. 权利和复用条件明确的官方无水印原始素材；
2. 用户或权利方授权的无水印素材；
3. Seedance 2.0 生成的非复刻式 AI 示意画面。

如果授权或水印状态不明确，直接选择 AI 示意画面。AI 画面不得复刻原视频人物、独特构图、标志性镜头或品牌视觉；需要时在画面或发布说明中标注“AI 生成画面/示意画面”。

## 9. 水印与版权质检

合成前和成片后各执行一次质检：

- 平台 Logo 和角标检测；
- 账号昵称、用户 ID、二维码检测；
- 滚动水印和半透明水印检查；
- 授权来源记录检查；
- AI 示意画面标识检查；
- 素材与热点证据对象混用检查。

判定规则采用 fail-closed：检测到水印或无法确定授权状态时，该素材不可用。系统不得提供或调用去水印流程。

## 10. 手动模式的热点确认卡

第一确认点固定输出 3 张候选卡（不足时按真实数量输出），每张包括：

1. 热点标题与一句话事实摘要；
2. 覆盖平台和每个平台的原始来源链接；
3. 采集时间与发布时间；
4. 可见点赞、评论、收藏、分享、播放量；
5. 缺失字段的明确说明；
6. 平台内相对热度和跨平台共振分析；
7. 权威核验来源及可信结论；
8. 主要受众情绪和评论洞察；
9. 风险提示；
10. 建议讲解角度；
11. 成片素材方案：授权无水印素材或 Seedance AI 示意画面。

用户选择一个热点后才进入脚本生成。脚本确认后，才自动进入 TTS、数字主持人、Seedance、合成和质检。

## 11. 故障与降级

- 某平台未登录：标记 `login_required`，不伪装采集成功。
- 页面结构变化：标记 `selector_or_ui_changed`，保存最小故障证据。
- 互动数据不可见：字段为 `null`，仍可保留来源但降低完整度。
- 视频号无法自动读取：允许浏览器辅助的结构化导入，明确标注采集方式。
- 单个平台失败：继续其他平台，但候选仍必须满足正式入池标准。
- 三个平台均不可用：停止热点流程，返回环境问题，不自动改用普通网页热搜冒充三平台结果。
- 采集频率受限：停止或退避，不绕过验证码、风控或平台访问限制。

## 12. 安全与合规边界

- 只访问用户正常登录后可见且允许访问的页面；
- 不绕过验证码、登录、付费墙、访问控制或反爬机制；
- 不导出、打印或持久化认证凭据；
- 不进行账号互动；
- 使用有限频率和人工可观察的浏览器操作；
- 不把平台数据抓取能力描述为永久可用，每次运行均重新探测；
- 所有来源保留采集时间和方法，支持审计。

## 13. 实施范围

本阶段实现：

1. 三平台采集能力探测；
2. Chrome 登录态只读采集输入协议；
3. 抖音、小红书浏览器采集适配；
4. 视频号浏览器辅助适配与结构化导入；
5. 统一来源记录、互动数据可见性和原始证据归档；
6. 跨平台去重、热点聚类、入池门槛和 Top 3 报告；
7. 权威事实核验记录；
8. 热点证据与成片素材隔离；
9. 无水印/授权状态检查和 AI 示意画面回退规则；
10. 与现有 `hotspot_review` 确认点连接。

不在本阶段实现：

- 自动发布；
- 平台账号互动；
- 去水印；
- 绕过平台安全机制；
- 将公众号文章计为视频号热度；
- 未经授权下载并剪辑平台热门视频。

## 14. 验收标准

1. 报告中的每条平台来源都能追溯到真实平台、采集时间和采集方式。
2. 不可见互动字段显示为未知，不出现估算或虚构数据。
3. Top 3 每项满足“双平台出现”或“单平台高热 + 权威证实”。
4. 未核验或风险内容不会进入正式候选池。
5. 最近 72 小时不足时才扩展到最近 7 天，并明确标记。
6. 视频号和公众号来源不会混淆。
7. Chrome 凭据不进入项目文件或日志。
8. 热点视频不会被自动送入成片素材流程。
9. 带水印或授权不明素材被拒绝，不存在去水印路径。
10. 手动模式只在热点、脚本和最终视频三个节点等待用户确认。
