# 固定数字主持人母参考图设计规格

## 1. 目标

为热点新闻短视频工作流固定唯一数字主持人形象，并生成可长期复用的坐播母参考图。主持人承担开场、解释、串联和总结；热点事实与插播新闻画面仍是内容主体。

## 2. 角色身份

- 主持人 ID：`fixed-seated-anchor`
- 姓名：林知遥
- 定位：虚构的成熟陪伴型女性新闻主持人
- 年龄观感：32–35 岁（系统允许范围 30–36 岁）
- 核心气质：成熟、专业、可信、温和、克制
- 固定音色：`宣传女生Pro:clone_20260806_114837_980375`

该人物不对应任何真实电视台、政府机构、记者、公众人物或现实中的具体个人。

## 3. 外观规格

- 成年东亚女性，面部比例自然端正；不模仿真实公众人物。
- 温和专注的眼神，轻微职业微笑，不过度严肃或娱乐化。
- 深黑色中长发，柔和侧分，发梢自然内扣，面部轮廓与嘴部无遮挡。
- 清透、自然的职业妆；不采用烟熏妆、浓艳红唇或夸张修饰。
- 深海军蓝合体西装外套，象牙白衬衫；无徽章、肩章、Logo 或醒目首饰。

## 4. 姿态与构图

- 固定坐播，坐于简洁的现代演播桌后。
- 腰部以上正面中景，身体和头部基本朝向镜头。
- 坐姿端正但不僵硬，肩部放松，直视镜头。
- 双手自然放在桌面下方或主体画面次要区域，避免手部成为视觉重点。
- 嘴部完整清晰、无遮挡，适合 image + TTS 的口型驱动。
- 竖屏 9:16，目标尺寸 1080×1920，人物居中并保留适度头顶空间。

## 5. 演播室与光线

- 完全虚构的安静现代演播室。
- 主色为克制的深蓝、蓝灰和柔和中性灰。
- 背景为抽象漫射面板与轻微景深，不出现可读屏幕信息。
- 使用平衡、柔和的演播室主光和补光，肤色自然，五官清晰。
- 整体为高质量写实编辑摄影，而非插画、卡通或强烈电影特效风格。

## 6. 禁止元素

不得出现：

- 警服、军装、警徽、政府徽章、肩章；
- 真实电视台 Logo、真实栏目名称或仿冒权威媒体标识；
- 真实公众人物相似面孔；
- 性感姿势、暴露服装、迷你裙、高跟鞋或身体曲线强调；
- 审讯室、警察局、监狱铁栏、通缉令或失踪人口海报；
- 可读文字、字幕、姓名条、台标、水印；
- 遮挡嘴部的麦克风、电话或其他物体；
- 多余人物、畸形手、异常肢体和过度磨皮。

## 7. 资产与复用规则

母参考图保存为：

```text
assets/hosts/fixed-seated-anchor/master-reference.png
```

角色身份档案和生成提示词保存为：

```text
assets/hosts/fixed-seated-anchor/identity.yaml
assets/hosts/fixed-seated-anchor/prompt.md
```

所有常规节目统一使用这张母参考图与固定音色。每日生产不得自动更换人物面孔、发型、服装或演播室风格。只有用户明确提出主持人改版时，才建立新版本并重新确认。

## 8. 验收标准

母参考图必须同时满足：

1. 角色符合成熟、专业、可信、温和的定位；
2. 服装和演播室不包含真实机构或媒体身份元素；
3. 画面为 9:16 坐播腰部以上构图；
4. 面部正向、清晰，嘴部无遮挡，能够用于数字人口型生成；
5. 无字幕、台标、姓名条、可读文字和水印；
6. 视觉重点克制，不抢夺热点内容与插播画面的注意力；
7. 资产路径、主持人 ID 和固定 TTS 音色能被工作流稳定引用。
